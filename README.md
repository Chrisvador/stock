# Stock Cevilog

Application web installable (ordinateur, iPhone, iPad) pour le matériel Cevilog : stock réel, labo / démo avec dépréciation en %, attente de livraison client, entrées, sorties, transferts et inventaire (case « vérifié »).

Données dans Supabase (tables `stk_orgs`, `stk_membres`, `stk_articles`, `stk_mouvements`, `stk_config`). Accès sur invitation par code, indépendant de l'app Mes chats, avec trois rôles : administrateur, membre, lecture seule. L'écran « Utilisateurs » gère les accès.
