# Stock Cevilog

Application web installable (ordinateur, iPhone, iPad) pour le matériel Cevilog : stock réel, labo / démo avec dépréciation en %, attente de livraison client, entrées, sorties, transferts et inventaire (case « vérifié »).

Données dans Supabase (projet `mes-chats`, tables `stk_articles`, `stk_mouvements`, `stk_config`), partagées entre les membres du foyer : mêmes comptes que l'app Mes chats.
